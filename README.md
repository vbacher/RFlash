# RFlash

This is the repository releasing the Code for the paper: "Shadow Reduction in Ultrasound Imaging using Differentiable Simulation and Radiance Field Decomposition".

## Data

This demo is meant to work with the following data:

| Dataset/Sample | Location | Comments |
|----------------|----------|----------|
| Fetal brain ultrasound | data/fetal_brain | 3D Ultrasound volume of the fetal brain |
| Abdominal ultrasound | [US simulation & segmentation](https://www.kaggle.com/datasets/ignaciorlando/ussimandsegm) | Abdominal ultrasound images. We recommend only using the real ultrasound images (RUS) for testing, it has not been tested for their simulated samples.|
| Synthetic liver ultrasound | [Synthetic liver ultrasound](https://github.com/magdalena-wysocki/ultra-nerf/tree/main/data/synthetic_testing) | The demo as for now only supports the images.npy files.
